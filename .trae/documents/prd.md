# 自动简历投递助手 - 产品需求文档

## 1. 产品概述
一款智能简历投递工具，帮助求职者自动化在多个招聘平台投递简历，提高求职效率。
- 解决求职者需要在多个平台重复投递简历的痛点，节省时间和精力
- 目标用户：正在求职的职场人士、应届毕业生，帮助他们高效管理求职流程

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|---------|
| 普通用户 | 邮箱/手机号注册 | 简历管理、平台账号绑定、自动投递设置、投递记录查看 |

### 2.2 功能模块
1. **仪表盘页面**：数据概览、快捷操作、最近投递记录
2. **简历管理页面**：简历上传、编辑、版本管理
3. **平台管理页面**：招聘平台账号绑定、授权管理
4. **投递设置页面**：职位筛选条件、投递策略配置
5. **投递记录页面**：投递历史、状态追踪、统计分析

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 仪表盘 | 数据概览卡片 | 显示今日投递数、总投递数、待回复数、面试邀请数 |
| 仪表盘 | 快捷操作区 | 一键投递、快速筛选职位入口 |
| 仪表盘 | 最近投递列表 | 显示最近10条投递记录及状态 |
| 简历管理 | 简历列表 | 展示所有简历版本，支持预览、编辑、删除 |
| 简历管理 | 简历编辑器 | 在线编辑简历内容、格式调整 |
| 平台管理 | 平台列表 | 显示支持的招聘平台及绑定状态 |
| 平台管理 | 账号绑定 | 扫码登录/账号密码登录各平台 |
| 投递设置 | 筛选条件 | 设置职位关键词、薪资范围、地点、公司规模等 |
| 投递设置 | 投递策略 | 设置每日投递上限、投递间隔、自动打招呼语 |
| 投递记录 | 记录列表 | 分页展示所有投递记录，支持筛选搜索 |
| 投递记录 | 状态追踪 | 显示投递状态（已投递、已查看、待沟通、已拒绝） |
| 投递记录 | 统计图表 | 投递趋势图、平台分布图、状态统计图 |

## 3. 核心流程

### 3.1 用户使用流程
用户注册登录 → 上传/创建简历 → 绑定招聘平台账号 → 设置投递条件 → 启动自动投递 → 查看投递记录和反馈

### 3.2 自动投递流程
```mermaid
flowchart TD
    "A[启动自动投递]" --> "B[获取筛选条件]"
    "B" --> "C[调用平台API搜索职位]"
    "C" --> "D{是否有符合条件的职位}"
    "D" --> "是" --> "E[检查是否已投递]"
    "E" --> "F{是否重复}"
    "F" --> "否" --> "G[发送投递请求]"
    "F" --> "是" --> "H[跳过该职位]"
    "G" --> "I[记录投递日志]"
    "H" --> "J{是否达到每日上限}"
    "I" --> "J"
    "D" --> "否" --> "K[等待下一轮]"
    "J" --> "否" --> "C"
    "J" --> "是" --> "L[停止投递，发送通知]"
    "K" --> "C"
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色系（#1E3A5F）配合活力橙色（#FF6B35）作为强调色，传达专业与活力
- **辅助色**：浅灰色背景（#F5F7FA）、白色卡片、深灰色文字
- **按钮风格**：圆角按钮（8px），主要操作使用实心按钮，次要操作使用边框按钮
- **字体**：标题使用思源黑体（Source Han Sans），正文使用系统默认字体
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局
- **图标风格**：线性图标，统一2px线宽

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 仪表盘 | 数据概览卡片 | 4个统计卡片，渐变背景，数字大字体突出 |
| 仪表盘 | 快捷操作区 | 大按钮设计，带图标，悬停动效 |
| 仪表盘 | 最近投递列表 | 表格形式，状态标签彩色区分 |
| 简历管理 | 简历列表 | 卡片网格布局，每个卡片显示简历预览缩略图 |
| 平台管理 | 平台列表 | 横向卡片，平台logo、绑定状态开关 |
| 投递设置 | 筛选条件 | 表单布局，下拉选择、输入框、范围滑块 |
| 投递设置 | 投递策略 | 开关控件、数字输入、文本域 |
| 投递记录 | 记录列表 | 表格布局，支持排序筛选 |
| 投递记录 | 统计图表 | 折线图、饼图、柱状图 |

### 4.3 响应式设计
- 桌面优先设计，最小支持1366px宽度
- 平板端（768px-1366px）：侧边栏可折叠
- 移动端（<768px）：底部导航栏，单列布局

### 4.4 交互动效
- 页面加载：骨架屏加载效果
- 卡片悬停：轻微上浮 + 阴影加深
- 按钮点击：涟漪效果
- 状态切换：平滑过渡动画（300ms）
- 数据更新：数字滚动动画
